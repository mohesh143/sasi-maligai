Sasi Maligai - Visual Beginner Guide

Welcome! Follow the numbered steps from the top. Each step says what you are doing, why, where to click, what to type, and what you should see. Red boxes and numbers in the pictures show where to look.

You need: a Windows laptop, internet for the first download, and about 30 minutes. You do not need to run npm install. Shop data is never deleted when the website starts.

Steps
  1. Check whether Node.js is already installed
  2. Install Node.js (free)
  3. Unzip the project to your Desktop
  4. Start the website
  5. Understand the black window
  6. Open the website in your browser
  7. Create your admin account (first time only)
  8. Log in again later
  9. Stop the website
  10. Start it again later
  11. Add your first real product
  12. Switch a product between Available and Out of stock
  13. Change your phone number, address and opening hours
  14. Make a backup
  15. Copy the backup to a USB drive
  16. Restore a backup (only when you really need it)

Part 1 - Install (once)

1Check whether Node.js is already installed

What you are doing: Asking Windows if the program called Node.js is on this computer. Node.js is the engine that runs the website.

Why: If it is already installed (version 22.16 or higher) you can skip the download.

Where to click / what to do

  1. Click the Windows Start button (bottom-left).
  2. Type: cmd
  3. Press Enter. A black window opens - this is the Command Prompt.
  4. Type the command below and press Enter.

Type exactly this (then press Enter)

node --version
You should see: A number such as v24.11.0 appears. If the first number is 22.16 or higher, skip to STEP 3.
If it fails: If you see 'node is not recognized...' it is simply not installed yet - continue with STEP 2. If the number is lower than 22.16, do STEP 2 too (it upgrades).

2Install Node.js (free)

What you are doing: Downloading and installing Node.js from its official website.

Why: The website needs Node.js to run. It is free and safe. You do NOT need to run 'npm install' for this project - nothing else must be downloaded.

Where to click / what to do

  1. Open your browser and go to nodejs.org
  2. Click the big green button that says LTS (Long Term Support).
  3. Open the downloaded file (it ends with .msi).
  4. Click Next on every screen. Keep all the default choices. Click Install, then Finish.
  5. Restart the computer (this lets Windows notice the new program).
You should see: After restarting, repeat STEP 1: node --version now shows a number.
If it fails: If the installer says you need an administrator password, or the computer blocks installing programs (common on government laptops), ask the person who manages the laptop to install it. See 10-TROUBLESHOOTING.md, problem 1 for an advanced fallback.

3Unzip the project to your Desktop

What you are doing: Extracting the ZIP file so that Windows can use the files inside.

Why: You cannot run a website from inside a ZIP file - it must be unzipped into a normal folder.

Where to click / what to do

  1. Find the file Sasi-Maligai-Final.zip (probably in Downloads).
  2. Right-click it and choose Extract All...
  3. Choose the Desktop as the destination, then press Extract.
  4. Open the new folder. Inside you must see start.bat, a folder called client and a folder called server.
You should see: You can see start.bat directly inside the folder you opened.
If it fails: If you only see ANOTHER folder (for example sasi-maligai inside sasi-maligai), open that inner folder - it is the real one.

Part 2 - Start the website

4Start the website

What you are doing: Double-clicking start.bat. It checks that Node.js is installed and then starts the website.

Why: start.bat does everything for you, so you never type commands to run the shop website.

Where to click / what to do

  1. Open the sasi-maligai folder.
  2. Double-click start.bat.
  3. If a blue 'Windows protected your PC' box appears, click More info, then Run anyway (it is your own file).
You should see: A black window opens and shows 'Sasi Maligai website is running!' and your browser opens by itself.
If it fails: If the black window closes at once, or shows a message about Node.js, see 10-TROUBLESHOOTING.md (problems 1, 4, 13).

5Understand the black window

What you are doing: Reading what the black Command Prompt window is telling you.

Why: That window IS the website server. If you close it, the website stops. Many beginners close it by accident.

Where to click / what to do

  1. Lines starting with [database] are normal start-up messages.
  2. 'Website : http://localhost:3000' is the address of the customer website.
  3. 'Admin : http://localhost:3000/admin/login.html' is the address of your admin panel.
  4. Leave the window open (you may minimise it with the _ button).
You should see: The window stays open, with no red error messages.
If it fails: A message such as 'Port 3000 is already in use' means the website is already running (see STEP 7 and problem 4).

6Open the website in your browser

What you are doing: Looking at the customer website.

Why: This confirms everything works.

Where to click / what to do

  1. Your browser should have opened by itself. If not, open Chrome or Edge.
  2. Click the address bar at the top, type the address below and press Enter.

Type exactly this (then press Enter)

http://localhost:3000
You should see: The Sasi Maligai home page appears with category tiles and sample products.
If it fails: If you see 'This site can't be reached', the black window is closed - do STEP 1 again.

7Create your admin account (first time only)

What you are doing: Choosing the username and password that protect your admin panel.

Why: Only you should be able to change prices and products. There is NO default password - you choose your own.

Where to click / what to do

  1. In the browser address bar type the admin address below and press Enter.
  2. You see 'Create your admin account'.
  3. Type a username (letters and numbers, for example: owner).
  4. Type a strong password of at least 8 characters, then type it again.
  5. Press Create account.
  6. WRITE THE PASSWORD ON PAPER and keep it somewhere safe.

Type exactly this (then press Enter)

http://localhost:3000/admin/login.html
You should see: You land on the Dashboard.
If it fails: 'The two passwords are not the same' - type them again carefully. 'The admin account can only be created from the shop computer' - you must do this step on the computer that runs the website, not on a phone.

8Log in again later

What you are doing: Using your username and password on later days.

Why: The login lasts 8 hours of inactivity; restarting the website also logs you out. This is normal and safe.

Where to click / what to do

  1. Go to the admin address (below).
  2. Type your username and password.
  3. Press Log in.

Type exactly this (then press Enter)

http://localhost:3000/admin/login.html
You should see: The Dashboard appears.
If it fails: After 5 wrong passwords the login waits 5 minutes. If you forgot the password, double-click reset-admin-password.bat (see 10-TROUBLESHOOTING.md, problem 7).

9Stop the website

What you are doing: Switching the website off properly.

Why: Stopping lets the computer rest. Your shop data stays safe on disk.

Where to click / what to do

  1. Easiest: click the X of the black window.
  2. Or: double-click stop.bat in the project folder.
  3. Or: click inside the black window and press CTRL+C.
You should see: The website no longer opens in the browser. Your data is not lost.
If it fails: If stop.bat says 'The website was not running' it is already stopped.

10Start it again later

What you are doing: Starting the website on another day or after restarting Windows.

Why: The website does not start by itself. Your products, pictures, settings, feedback and admin login are all still there.

Where to click / what to do

  1. Double-click start.bat again.
  2. Open http://localhost:3000
You should see: Everything you added earlier is still there. The website NEVER resets the database when it starts.
If it fails: If something looks empty, do not panic: open Admin > Backup & Restore and restore your latest backup (07-BACKUP-RESTORE.md).

Part 3 - Daily use, backup and restore

11Add your first real product

What you are doing: Putting one product on your website.

Why: Customers see products only after you add them.

Where to click / what to do

  1. Log in to the admin panel.
  2. Click Products in the menu.
  3. Click + Add product.
  4. Type the product name and choose the Category.
  5. Type the Price (numbers only) and choose the Unit (kg, litre, packet ...).
  6. Optional: choose a Picture. Big photos are made smaller automatically.
  7. Keep 'Available in the shop now' ticked and press Save product.
You should see: The product appears in the list. Open the customer website > Products and you can see it.
If it fails: A red message tells you what to fix (for example 'Price must be a number'). Fix it and press Save product again.

12Switch a product between Available and Out of stock

What you are doing: Telling customers an item is finished.

Why: It takes one click, so you can do it many times a day.

Where to click / what to do

  1. Admin > Products.
  2. Click the green Available button of the product. It turns red: Out of stock.
  3. Click it again when the stock returns.
You should see: On the customer website the product shows 'Not available now'.

13Change your phone number, address and opening hours

What you are doing: Editing the shop details shown on the website.

Why: No file editing is needed - you change everything here.

Where to click / what to do

  1. Admin > Shop settings.
  2. Type your Phone, WhatsApp number, Address and Opening hours.
  3. Press Save settings.
  4. Open the customer website and refresh (press F5).
You should see: Your new details appear on the Home and Contact pages.
If it fails: If the WhatsApp button does not appear, the WhatsApp box is empty - fill it in.

14Make a backup

What you are doing: Saving a safe copy of all your shop data.

Why: If the computer breaks or someone deletes products by mistake, a backup brings everything back.

Where to click / what to do

  1. Admin > Backup & Restore.
  2. Press Create backup now.
You should see: A new line appears, named like sasi-maligai-backup-2026-10-02-143000.db.
If it fails: If it fails, the disk may be full - free some space and try again.

15Copy the backup to a USB drive

What you are doing: Keeping a copy OUTSIDE the computer.

Why: If the computer itself is lost, a backup on the same computer is lost too.

Where to click / what to do

  1. Plug in the USB drive.
  2. Open the sasi-maligai folder.
  3. Right-click the backups folder > Copy.
  4. Open the USB drive, right-click an empty space > Paste.
  5. Do the same with the uploads folder (product pictures).
You should see: The USB drive now contains backups and uploads folders.

16Restore a backup (only when you really need it)

What you are doing: Going back to the data saved in a backup.

Why: It undoes mistakes. It replaces the CURRENT data, so the website first saves a safety copy of the current data automatically.

Where to click / what to do

  1. Admin > Backup & Restore.
  2. Find the backup in the list and press Restore.
  3. A box shows how many products are in the backup and how many you have now - read it.
  4. If you are sure, press Yes, restore this backup. Otherwise press Cancel and nothing changes.
  5. You are logged out. Log in again with the password that was valid when that backup was made.
You should see: Your old data is back. No restart is needed. The safety copy is named sasi-maligai-before-restore-....db and stays in the backups list.
If it fails: 'This backup cannot be used' means the file is damaged or is not a Sasi Maligai backup; nothing was changed. Try a different backup.
